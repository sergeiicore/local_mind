# Local Mind

Local Mind — macOS-приложение для быстрых мыслей, напоминаний и событий. Оно сохраняет исходный текст локально, создаёт события только после подтверждения и не отправляет весь Obsidian в AI.

## Что уже работает

- `⌃⌥Space` открывает или прячет компактную правую верхнюю панель поверх других окон, `⌃⌥⇧Space` — открывает её и запускает локальную диктовку.
- Текст и диктовка сохраняются в локальное хранилище; закрытие окна не завершает приложение — оно остаётся в строке меню.
- Obsidian: подключается через Settings и использует только `Local Mind/Incoming` и `Local Mind/Notes` внутри выбранного vault.
- Calendar: выбранное событие создаётся только после карточки подтверждения. Экран календаря отсутствует: события подмешиваются в контекст только для вопросов о плане и расписании. Для Android выберите в Calendar на Mac календарь Google-аккаунта, который синхронизируется с телефоном.
- Telegram: личный бот принимает текстовые мысли и присылает запланированные напоминания, пока Mac включён.
- Todoist: выбранные задачи можно дополнительно отправить в Todoist.
- AI: Codex CLI подключается одним нажатием через текущий вход. Также доступны Ollama, OpenAI API и совместимые API; ключи хранятся в Keychain. Никаких `.env` файлов нет.

## Первый запуск

Запустите приложение и нажмите `LM` справа в строке меню. Левый клик открывает панель, правый — служебное меню. Значки в панели ведут к истории и подключениям. Все пути и токены вводятся в интерфейсе. Токены не пишутся в `state.json` и не попадут в Obsidian.

Самый быстрый вариант — открыть **AI** и нажать **Подключить** рядом с Codex CLI. Local Mind запускает `codex exec` в read-only и ephemeral-режиме и использует сохранённую авторизацию CLI; логин и токены не копируются в приложение. Для Ollama и OpenAI API есть короткие готовые пресеты.

## Постоянная установка и автозапуск

Соберите release-версию, переместите `build/macos/Build/Products/Release/Local Mind.app` в папку «Программы» и запускайте её оттуда. После первого запуска справа в строке меню появится `LM`. Нажмите его правой кнопкой и включите «Запускать при входе в Mac» — приложение будет стартовать вместе с учётной записью и оставаться в строке меню. Для иконки в строке меню отдельное разрешение macOS не требуется; разрешения на микрофон и распознавание речи запрашиваются только при первой диктовке.

## Codex и другие MCP-клиенты

`tools/local_mind_mcp.py` — локальный MCP stdio-сервер без зависимостей и без переменных окружения. Он предоставляет два безопасных инструмента: сохранить дословную мысль во входящие и прочитать компактный список локальных записей. Он не получает доступ к Calendar, Telegram, Obsidian целиком или Keychain.

Добавьте в конфигурацию MCP-клиента путь к скрипту:

```json
{
  "mcpServers": {
    "local-mind": {
      "command": "python3",
      "args": ["/ABSOLUTE/PATH/TO/local_mind/tools/local_mind_mcp.py"]
    }
  }
}
```

Путь указывается один раз при подключении клиента. Мост кладёт Markdown в `~/Library/Application Support/Local Mind/Bridge/Incoming`, а Local Mind подхватывает его в течение 30 секунд.
